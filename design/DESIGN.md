## 1. เป้าหมายและเหตุผล

เว็บเดิมใช้ดำทองและลายลาวอยู่แล้ว แต่ลายทำออกมาหยาบ (หน้าบันสามเหลี่ยมมีหนาม สีน้ำเงิน/แดง/เขียวตีกัน พื้นหลังลายตาข่ายทั่วไป แถบตีนซิ่นเล็กเหมือนดิ้น) เว็บใหม่ต้อง:

- **ดูเป็นลาวแท้** — ลายต้องมาจากศิลปะลาวจริง ไม่ใช่ลายเอเชียทั่วไป
- **ระดับโปรดักชั่น** — เทียบชั้นเว็บที่ได้รางวัลปี 2026 ใช้ Three.js เป็นหัวใจของประสบการณ์
- **ใช้งานได้จริง** — ลูกค้าหลักคือนักธุรกิจ/นักลงทุน (ลาว จีน ต่างชาติ) ที่ต้องหาบริการและติดต่อได้เร็ว
- **เนื้อหาเหมือนเดิม** — ใช้ไฟล์ YAML 3 ภาษาเดิมใน `MVMGROUP.LA/content/` ทั้งหมด

**ไม่ทำ (Non-goals):** ระบบสมาชิก, ขายของออนไลน์, ระบบจองทัวร์ (เพิ่มทีหลังได้)

**ถือว่าล้มเหลวถ้า (Anti-goals):**
- สวยแต่โหลดช้าบนมือถือ หรือคนต้อง "เล่น" ก่อนถึงจะหาข้อมูลเจอ
- ดูเหมือนวัดหรือโรงแรม แทนที่จะดูเป็นกลุ่มบริษัท
- ลายลาวผิดทรงหรือหยาบแบบเว็บเดิม
- เปิดในจีนไม่ได้เพราะพึ่ง Google

## 2. แนวคิดหลัก: "ລາຍຄຳ — แสงเทียนในสิมลงรักปิดทอง"

ที่มา: ผนังภายในสิมวัดเชียงทอง หลวงพระบาง (ค.ศ. 1560) เป็นรักดำลายฉลุทอง (ลายคำ) — ศิลปะ "ดำทอง" ของลาวแท้ ไม่ใช่สีที่เราคิดเอง (ดูภาพ `references/xt-black-gold-interior.jpg`, `xt-golden-wall.jpg`)

ประสบการณ์: ผู้เข้าชมเหมือนเดินเข้าสิมยามค่ำ **เมาส์/นิ้วคือแสงเทียน** — ลายทองบนผนังรักดำจะสว่างวาวขึ้นตรงที่แสงส่อง ฝุ่นทองลอยในอากาศ (เหมือนแผ่นทองคำเปลวที่คนลาวปิดถวาย)

## 3. แนวทางที่พิจารณา (Approaches)

| แนวทาง | ข้อดี | ข้อเสีย | ผล |
|---|---|---|---|
| **A. โลก 3D ทั้งเว็บ** (แบบ Bruno Simon — ขับรถ/เดินสำรวจ) | ว้าวสุด ได้รางวัลง่าย | ลูกค้าธุรกิจหาข้อมูลยาก, SEO แย่, มือถือหนัก | ❌ ขัดกับเป้าหมายใช้งานจริง |
| **B. 3D เป็นหัวใจหน้าแรก + เรื่องเล่าตามการเลื่อน, หน้าข้อมูลเป็น HTML ที่มี 3D เล็กๆ** (แบบ Hubtown, Cartier, Shopify Editions) | ว้าวตั้งแต่เปิด แต่ข้อมูลเป็น HTML จริง อ่านง่าย SEO ดี โหลดเร็ว | งานมากกว่าเว็บธรรมดา | เลือกครั้งแรก → **เจ้าของเปลี่ยนเป็น D** (เลื่อนยาวเกินไป) |
| **D. จอเดียวแบบแอป: ฉาก 3D ค้างอยู่ตลอด, เนื้อหาเปิดเป็นหน้าต่างทับ, แต่ละหน้าต่างมี URL จริง** | ไม่ต้องเลื่อนหน้า, รู้สึกเป็นประสบการณ์เดียว, SEO ยังดีเพราะทุก URL เป็น HTML | การนำทางซับซ้อนกว่า | ✅ **เลือก (22 ต.ค.)** |
| **C. ไม่มี 3D ใช้แค่แอนิเมชัน CSS** | ง่าย เร็ว | ไม่ตรงที่เจ้าของต้องการ (Three.js) | ❌ |

## 4. ประสบการณ์ 3D (Three.js) — ฉบับแก้ 22 ต.ค. 2026

> แก้ตามเจ้าของ: พระธาตุ 3D ไม่สวย → เปลี่ยนเป็นโลโก้ MVM ทอง 3D, และไม่ต้องการหน้ายาวที่เลื่อนลงมาก → **จอเดียวแบบแอป** สิ่งที่เจ้าของชอบและต้องเก็บไว้: พื้นหลังลายทองที่สว่างตามเมาส์

### จอหลัก (ไม่เลื่อนหน้า)
- **พื้นหลัง:** ผนังรักดำลายขอทอง สว่างตามแสงเทียน (เมาส์/นิ้ว) + ฝุ่นทองลอย — เหมือนต้นแบบที่เจ้าของชอบ
- **กลางจอ:** โลโก้ MVM ทองนูน 3D สร้างจากไฟล์เวกเตอร์จริง (`public/brand/logo-emblem.svg`) หมุนช้าๆ สะท้อนแสงเทียน
- **วงล้อ 8 ซี่:** 8 ธุรกิจเรียงเป็นวงรอบโลโก้ เหมือนธรรมจักร 8 ซี่ (มีบนเพดานวัดเชียงทอง) ชี้ที่ธุรกิจไหน โลโก้หันไปทางนั้นและแสงทองวิ่งตามซี่
- **เมนูเล็ก:** เกี่ยวกับ · ผลงาน · ข่าว · ติดต่อ · สลับภาษา
- **มือถือ:** โลโก้อยู่บน 8 ธุรกิจเป็นรายการ 2 คอลัมน์ใต้โลโก้ ยังจบในจอเดียว

### หน้าต่างเนื้อหา
- กดธุรกิจ/เมนู → หน้าต่างรักดำเลื่อนเข้ามาทับพื้นหลังทอง (พื้นหลังยังขยับตามเมาส์อยู่ด้านหลัง จางลง)
- **เนื้อหายาวเลื่อนภายในหน้าต่างเท่านั้น** หน้าเว็บหลักไม่เลื่อน — เนื้อหาครบเหมือนเว็บเดิม (ขั้นตอน, เอกสาร, FAQ, โปรแกรมทัวร์รายวัน, บทความ, ฟอร์ม)
- ปิดด้วยปุ่ม ✕, กด Esc, หรือปุ่มย้อนกลับของเบราว์เซอร์

### ลิงก์และ SEO (การตัดสินใจของผม — แก้ได้)
- ทุกหน้าต่างยังมี URL ของตัวเองเหมือนเว็บเดิม เช่น `/la/services/tour-travel/` — แชร์ได้, Google เก็บได้, เปิดลิงก์ตรงแล้วเห็นหน้าต่างนั้นเปิดอยู่บนพื้นหลังทอง
- ทุก URL เป็นหน้า HTML จริง (Astro) การสลับหน้าต่างใช้ View Transitions ให้ลื่นเหมือนแอปโดยฉาก 3D ไม่โหลดใหม่

### กติกาที่ห้ามละเมิด
- เนื้อหาทุกอย่างเป็น HTML จริงก่อน 3D โหลดตามมาทีหลัง (Google อ่านได้, คนเห็นข้อมูลทันที)
- ผู้ใช้ที่ตั้ง "ลดการเคลื่อนไหว" หรือเครื่องอ่อน → เห็นภาพนิ่งสวยๆ แทน 3D
- มือถือ: ฉากเบาลง (อนุภาคน้อยลง ไม่มีเงา) แสงเทียนตามนิ้วที่แตะ
- ไม่มีอะไรต้องโฮเวอร์ถึงจะเห็น (มือถือไม่มีโฮเวอร์)

## 5. ระบบดีไซน์ (Design System)

### สี
| Token | ค่า | ใช้กับ |
|---|---|---|
| `--lacquer` | `#0E0B08` | พื้นหลังหลัก (รักดำ) |
| `--lacquer-2` | `#16120D` | การ์ด/แผง |
| `--lacquer-3` | `#221B13` | เส้นขอบ, hover |
| `--gold` | `#C9A45C` | ลาย, หัวข้อ, เส้น |
| `--gold-bright` | `#E8D19A` | ไฮไลต์, จุดที่แสงเทียนส่อง |
| `--gold-deep` | `#8C6A2E` | เงาทอง, ปุ่มกด |
| `--ivory` | `#F3ECDD` | ตัวหนังสือบนพื้นดำ |
| `--ivory-dim` | `#B8AE9C` | ตัวหนังสือรอง |
| `--vermilion` | `#7A2318` | สีชาด (จากผนังแดงวัดเชียงทอง) — ใช้น้อยมาก เฉพาะจุดเน้น |

ไม่มีน้ำเงิน/เขียว/แดงสด สลับกันอีกต่อไป ทุกธุรกิจใช้ดำทองเหมือนกัน ต่างกันที่ **ลาย** ไม่ใช่สี

### ตัวอักษร (ทุกตัว OFL ใช้เชิงพาณิชย์ได้ ดาวน์โหลดแล้วใน `fonts/`)
| บทบาท | อังกฤษ | ลาว | จีน |
|---|---|---|---|
| ตัวโชว์/หัวข้อใหญ่ | Cormorant (300–500) | Noto Serif Lao | Noto Serif SC |
| ตัวพิมพ์ใหญ่/ป้าย | Marcellus (เข้ากับโลโก้) | Noto Serif Lao | Noto Serif SC |
| เนื้อหา | Noto Sans | Noto Sans Lao | Noto Sans SC (ฟอนต์เครื่อง) |
| สำรองแบบราชการลาว | — | Phetsarath (ฟอนต์ทางการ สปป ลาว) | — |

ฟอนต์จีนจะตัดเฉพาะตัวอักษรที่ใช้ (subset) ตอน build ให้ไฟล์เล็ก และโฮสต์เองทั้งหมด (ไม่พึ่ง Google Fonts — เปิดในจีนได้)

### ลวดลาย (สร้างแล้วใน `patterns/` — แก้/สร้างใหม่ด้วย `generate.py`)
| ไฟล์ | ที่มา | ใช้ที่ |
|---|---|---|
| `khor-lozenge.svg` | ลายขอ/ข้าวหลามตัดตะขอ ของผ้าซิ่นทอ (วาดแบบตารางเส้นด้ายจริง) | สัญลักษณ์เล็ก, ตัวคั่น |
| `khor-lattice-tile.svg` | ลายเดียวกันเรียงต่อกัน | พื้นผิวแผงรักดำ (จางมาก 4–8%) |
| `sinh-border.svg` | แถบตีนซิ่น: ฟันปลา + โซ่ข้าวหลามตัด | ขอบบน/ล่างของส่วนต่างๆ, ท้ายเว็บ |
| `laikham-rosette.svg` | ดอกกลมลายคำ บนผนังวัดเชียงทอง | ตราประจำส่วน, 3D ที่หมุนได้ |
| `dok-champa.svg` | ดอกจำปา ดอกไม้ประจำชาติลาว | ตกแต่งเล็กๆ, ไอคอนโหลด |

กติกา: **ลายหนึ่งชิ้นต่อหนึ่งจุดสนใจ** ไม่ซ้อนลายหลายชั้นแบบเว็บเดิม

### ภาพถ่าย
- หลักฐานความเป็นลาว: ภาพจริงของวัดเชียงทอง, พระธาตุหลวง, ผ้าทอ (ดาวน์โหลดแล้ว มีใบอนุญาต)
- ปรับโทนภาพทุกภาพให้อุ่น เงาเข้ม เข้ากับดำทอง
- **ยังขาด:** ภาพบริษัทจริง (ออฟฟิศ ทีม งาน) และภาพสินค้าจริงของทั้ง 2 แบรนด์ — สำคัญมากต่อความน่าเชื่อถือ

### การเคลื่อนไหว
- ช้า นุ่ม มีน้ำหนัก (เหมือนแสงเทียน ไม่ใช่เหมือนแอปเกม)
- เลื่อนหน้าแบบลื่น (Lenis) + ฉากผูกกับการเลื่อน (GSAP ScrollTrigger)
- ระยะเวลามาตรฐาน: 600–1200ms, easing แบบ "expo out"

## 6. Stack (วิธีสร้าง)

| ส่วน | เลือก | เหตุผล |
|---|---|---|
| เฟรมเวิร์ก | **Astro** | หน้าเว็บเป็น HTML สำเร็จรูป เร็วสุด SEO ดี โหลด Three.js เฉพาะที่ต้องใช้ อ่าน YAML เดิมได้ตรงๆ |
| 3D | **Three.js r186** — `WebGPURenderer` (สำรองเป็น WebGL 2 อัตโนมัติ) + TSL shader | มาตรฐานปี 2026 รองรับ Safari/Chrome/Edge/Firefox |
| แอนิเมชัน | GSAP + ScrollTrigger, Lenis | สิ่งที่เว็บรางวัลปี 2026 ใช้ |
| สไตล์ | Tailwind CSS v4 + CSS variables ตามตารางสีด้านบน | |
| CMS / ฟอร์ม / โฮสต์ | Decap CMS + Netlify Forms + Netlify (เหมือนเดิม) | ทีมแก้เนื้อหาเองได้เหมือนเดิม |
| ทดสอบ | Playwright (Skill webapp-testing) + Lighthouse (Skill web-quality-audit) | |

**เป้าคุณภาพ:** LCP < 2.5 วิ บนมือถือ 4G, Lighthouse ≥ 90 ทุกหมวด, 3D รวม ≤ 1.5 MB, 60fps บนโน้ตบุ๊กทั่วไป, 30fps+ บนมือถือระดับกลาง

**Localhost:** โฟลเดอร์ `MVMGROUP.LA/mvm-redesign/` รันที่ `http://localhost:4400` (เว็บเดิมยังอยู่ที่ 4321 ไม่แตะต้อง)
